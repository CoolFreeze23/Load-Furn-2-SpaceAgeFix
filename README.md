## Advanced Furnaces 2 SpaceAgeFix

Adds 5 furnaces whose crafting speed follows transport belt speed, plus PRO loaders, belts, undergrounds and splitters.

### About this version

This is an unofficial update of Advanced Furnaces 2 for Factorio 2.1. It is not affiliated with or endorsed by the original authors.

- Original mod: **Advanced Furnaces 2** by LightningMaster (based on earlier work by fartdog).
- Loader snapping code originally from Loader Redux by Optera.
- Factorio 2.0 loader snapping fix (0.2.14) and Factorio 2.1 update (0.3.0), see `changelog.txt`.
